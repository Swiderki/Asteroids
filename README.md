# Quick Start

## How to Run the Game

To get started with the game, follow these steps:

1. Install dependencies:
   ```bash
   npm i
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

This will launch the game in development mode. Open your browser at the address provided in the terminal (usually http://localhost:5173/ or similar).

## Engine Documentation

The game was built using the Drake engine. You can find the full documentation here: [https://drake-docs.vercel.app/](https://drake-docs.vercel.app/)
